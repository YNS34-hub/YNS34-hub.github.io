# 个人世界 · 原生运动模式

本机 Unreal Engine 5.8 工程，包含训练馆与湖岸骑行两张可编辑地图。原博物馆网页、正在进行的篮球分支、动作实验室和私人媒体均在各自原目录中保留。本工程不发布网站，不上传媒体。

双击工程根目录的 **开始-篮球训练.cmd** 或 **开始-湖岸骑行.cmd**。启动脚本优先使用 `Delivery/Windows/MemorySports.exe`；尚未打包时使用本机已安装的 UE 5.8，以游戏模式启动。工程文件是 `MemorySports.uproject`。

| 功能 | 篮球训练 | 湖岸骑行 |
| --- | --- | --- |
| 移动 | WASD；Shift 加速 | W 踩踏；A / D 转向 |
| 主要操作 | E 收球 / 运球；X 换手 | Q / E 降挡 / 升挡 |
| 动作 | 按住左键蓄力、松开投篮；右键瞄准；空格跳跃 | 空格或 S 刹车；Shift 短时冲刺 |
| 动作包 | 1 切投篮包；2 切上篮包；3 切扣篮包；F 上篮；G 扣篮 | W + Shift 冲刺，界面显示实际功率与耐力 |
| 恢复 | R 回到训练起点 | R 回到附近道路；终点后重新开始 |
| 视角与系统 | V 第一 / 第三人称；H 操作提示；Esc 暂停；F9 截图；F10 退出 | 相同 |
| 切换模式 | F1 篮球 | F2 骑行 |

三种投篮节奏为快出手（0.46 秒）、经典跳投（0.62 秒）和高出手（0.78 秒）。三种上篮为长步、挑篮和欧洲步；两种扣篮为单手和双手。靠近篮圈后 F 上篮、G 扣篮，空中不能重复触发。1 / 2 / 3 切换的选择单独保存在 `Saved/motion-loadout.json`。篮球释放后使用 Chaos 球体碰撞，命中读取实际下降穿框；运球由角色动作节奏驱动。E 快速收球，方便连续练习。

骑行采用 120 Hz 固定步长的自定义动力学，包含功率、空气阻力、滚阻、坡度、挡位、刹车和冲刺耐力。玩家可自由转向，正常游戏不会沿轨道自动移动。原世界的约 3.53 km 路线、谷地和山体被转换为厘米制原生场景；这条谷地是创作地景，不代表测量后的真实地点。

角色复用原博物馆本机保存的人脸贴图和体型参数，以 MIT 授权的 Rocketbox 人体为基础，重新绑定至原生骨架。89 根参考骨骼经过位置、旋转检查，基础行走动作来自 Unreal 模板，手臂、脚踏接触由原生 IK 驱动。本人外观为贴图和体型适配，并非新采集的三维面扫。三类篮球动作是本工程原创参数化动作，未导入 2K 游戏文件，详见 `Docs/MOTION-SOURCES.md`。

骑行常规功率上限 195 W，短时冲刺上限 650 W，实际功率受踏频影响。起步扭矩、挡位和坡度会改变加速；耐力低于 8% 停止冲刺，恢复到 30% 才能再冲刺。刹车优先切断驱动力，避免边踩边刹仍推动车辆。车轮、踏板、曲柄与把手根据速度、踏频和转向运动。

天空、道路、草地、岩石和树冠复用原项目已署名的公开资源；来源见 `Docs/Road-SOURCES.md` 和 `Docs/Forest-SOURCES.md`。运动反馈音为本工程合成。Manny 及其基础资源来自本机 Unreal Engine 模板，记录在 `Docs/Engine-content.md`。

当前画质面向 GTX 1650 4GB / 16GB 内存，默认 DX11、1600 × 900、高档基础画质、约 60 FPS 上限。没有启用硬件光追和 Lumen。原生渲染截图、输入状态、测试日志和性能实测保存在 `Reports`；v0.3 结果以 `Reports/篮球细节与比赛呈现验收.md` 为准，`Reports/人物动作与骑行升级验收.md` 与 `Reports/验收记录.md` 保留为旧版记录，历史失败截图不会被隐藏。

骑行进度独立保存在本工程 `Saved/ride-progress.json`，不读取网页骑行存档。F9 只保存游戏视口，不捕获桌面或其他应用；图片压缩在后台执行，最多同时保存三张。独立包截图位于 `Delivery/Windows/MemorySports/Reports/Evidence`；编辑器游戏模式截图位于工程 `Reports/Evidence`。本轮新证据位于 `Reports/UpgradeEvidence`，当前结果见 `Reports/篮球细节与比赛呈现验收.md`。旧版证据继续保留。

重新编译使用 `Scripts/Build.ps1`。英文入口 `E:/Codex/UnrealSports` 是指向本工程的目录联接，用于规避本机 MSVC 的中文中间文件路径错误；源码没有搬离本目录。重编译依赖的真实微软 SDK 位于 `E:/Codex/UnrealSportsCache/Toolchain/NETFXSDK/4.8`，仅登记了当前用户的 SDK 发现路径。

在编辑器中可以直接编辑两张地图的灯光、材质和已保存组件。`Scripts/build_assets.py` 会重建这两张生成地图；需要保留手工编辑时，请先另存地图副本。本人角色生成使用 `Scripts/prepare_personal_avatar.py` 和 `Scripts/import_personal_avatar.py`；`normalize_athlete.py` 是早期实验工具。私人角色、贴图、运行包、包含人脸的渲染证据均只供本机使用，已加入忽略规则，不可公开上传。

旧版回退位置记录在 `Reports/v0.1-rollback.json` 与 `Reports/v0.2-rollback.json`，包含对应运行包和源码配置压缩包。v0.3 增加起跳/滞空/落地衔接、握球与松手手指、伸臂压腕随挥、真实命中后的篮网与场馆计分。界面采用 Barlow 字体和比赛计分布局，按 H 展开完整操作；出手反馈显示真实提前/延后毫秒数。字体来源及许可见 `Docs/UI-SOURCES.md`。

非持球手、出手后的双手沿身体两侧自然下垂；走动保留轻微摆臂。左右肘独立计算，抬手、出手和收手连续过渡，骑行仍保持握把。专项原生画面与实际骨骼下垂角度在 `Reports/arms-review-run.json` 和对应本机证据目录中。

最终水面采用原创周期风浪法线、双层不同尺度流动和浅水透明过渡，修正了原来的规则棋盘反光。水材质与法线可单独用 `Scripts/refine_water.py` 重建；完整场景生成也复用同一材质函数。最终湖岸近景、俯瞰及 30 秒性能记录位于 `Reports/final-details-run.json` 指向的本机目录。

验收使用 `-SportsQA` 时才会读取 `Saved/qa-sequence.json`。完整路线测试只通过 Unreal 玩家输入事件发送方向、踩踏和换挡，不在连续测试过程中修改玩家位置或速度；标有 `observation` 的定点截图单独记录。
