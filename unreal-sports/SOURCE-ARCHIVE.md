# Unreal 源码归档

2026-10-26 将本机 `unreal-sports` 的原创 C++、工程配置、生成与验收脚本、来源文档和启动入口同步到本仓库，保留原始实现；两份 INI 仅移除末尾空行。网页博物馆仍由仓库根目录的 Vite 工程运行。

这是源码归档，克隆后不能直接启动本机私人游戏包。工程依赖 Unreal Engine 5.8、微软编译工具，以及按脚本在本机准备的地图、模板与其他资源。脚本中的本机工程入口、引擎和原博物馆路径需要按实际安装位置配置。

`Content`、`InputAssets`、`Delivery`、二进制、缓存、存档和渲染证据不在归档范围。尤其不包含私人角色、人脸贴图、体型参数、训练媒体，以及 Unreal 模板资产。原项目的这些文件仍保存在原本机目录。来源与使用条件见 [Docs](Docs/)，历史本机操作说明见 [README](README.md)。

此次同步核对了归档文件与本机源码的逐文件摘要并检查脚本语法；没有重新编译或验收一个缺少私人资源的公开 Unreal 游戏包。README 中的历史运行与画面验收记录属于原本机工程。
