# Museum typography

Self-hosted variable fonts from the official Google Fonts repository, under SIL Open Font License 1.1. Corresponding licenses are included here. No commercial Canela / Neue Haas font is bundled.

| Role | Family | Source |
| --- | --- | --- |
| Exhibition title, 300 italic | Cormorant Garamond | [Official source](https://github.com/google/fonts/tree/main/ofl/cormorantgaramond), `OFL-cormorantgaramond.txt` |
| Quiet interface | Manrope | [Official source](https://github.com/google/fonts/tree/main/ofl/manrope), `OFL-manrope.txt` |
| Archive metadata | JetBrains Mono | [Official source](https://github.com/google/fonts/tree/main/ofl/jetbrainsmono), `OFL-jetbrainsmono.txt` |

The downloaded TTF bytes were verified against GitHub blob SHA-1 before lossless WOFF2 conversion with FontTools / Brotli. Glyphs and variable weight axes were retained. The WOFF2 files total 478,640 bytes. Conversion tools and original downloads remain in the ignored local QA directory, not a global Python installation.

Original TTF blob hashes:

- Cormorant Garamond italic: `0d914e7663b7a1429d06ec60a5c5bb026031a2ef`
- Cormorant Garamond regular: `d992a83ce525c330fad3a19087746bcb2dc038ee`
- Manrope: `75274da58537d6123b14f2cd0c355ad4681fc2b3`
- JetBrains Mono: `aa310be8b717fe3774f9444dd89d5f4101cc6d10`

The original self-hosted Space Grotesk files remain available for accepted legacy content. Chinese text falls back to the system Chinese typeface; the fonts do not pretend to include Chinese glyphs.
