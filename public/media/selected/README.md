# Selected collection

These 12 visual references were selected by Jie Tian from the folder supplied for this website. They are exhibited as **User-selected visual reference**, without an AI-origin or original-authorship claim. Four cinematic scenes also appear in the wallpaper vault.

The eight `projects/liquid-web/` files are actual desktop captures of the websites in Jie Tian's Liqud-web collection. The original HTML files remain in the private repository and in the local personal collection. Public builds include only these visual previews.

Neither this directory nor the public release contains commercial music.
