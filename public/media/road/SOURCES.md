# Road-cycling environment textures

These are public-domain CC0 assets from Poly Haven, resized/encoded as 1K WebP for this scene. They remain freely available from the original source. No private media is included.

- `asphalt.webp` and `asphalt-normal.webp`: [Asphalt 02](https://polyhaven.com/a/asphalt_02).
- `bark.webp` and `pine.webp`: only the bark and twig textures of [Pine Tree 01](https://polyhaven.com/a/pine_tree_01). This project uses original budgeted tree geometry, not the full high-poly model. The supplied twig alpha channel is preserved.
- `ground.webp`: [Forest Leaves 04](https://polyhaven.com/a/forest_leaves_04).

License: [Poly Haven CC0](https://polyhaven.com/license). All bicycle, road, terrain, architectural and UI geometry is original project code. The site does not use any commercial road-bike logos.
