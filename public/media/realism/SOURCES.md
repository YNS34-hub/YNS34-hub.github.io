# Material data

`court-wear.webp` is original deterministic material data generated by
`scripts/prepare-surface-wear.py` (seed 431960), not a photograph or a video frame.
It maps once to the existing 24 x 36 metre court. R = restrained coating variation;
G = dry surface roughness / foot-contact polish; B = sparse antialiased hairline wear.
All channels are linear data (`NoColorSpace`); the existing court artwork is retained.
No commercial logos, audio or private media are included.
