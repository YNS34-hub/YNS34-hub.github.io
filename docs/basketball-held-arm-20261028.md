# 自然双手持球与收球肩肘

2026-10-28 将双手持球的肘部目标改为实际肩线、骨长和手腕目标所允许的肘圆。目标保持低位分支，并受原有12厘米外移、20厘米下沉、35毫米腕残差与3毫米真实表面净空约束。站立、前后和横向走动使用同一肩部参考系，球随未解算胸肩做限幅随动，避免髋部转向拖偏双臂。

收球时记录实际左右肘与手腕，随同一收球时钟和身体位移过渡。蓄力阶段继续使用真实肘圆，消除旧固定目标靠近肩腕连线时的解算方向翻转。原生左右手、三种投篮包的六组收球肩关节连续性检查通过；原速度门限12rad/s加0.08rad容差保持。

复验入口为 `scripts/check-shot-gather-arms.mjs`。设置本机 `PALACE_URL` 和全新的 `PALACE_ARTIFACTS` 目录；可用 `PALACE_LOCAL_MEDIA_ROOT` 指向本机私人角色目录，实际选择并验证已加载的照片贴图。隔离浏览器不上传媒体，不注入动作相位或骨骼姿态。生成的截图和私人配置继续只保存在本机。

现有13项肩线自然度、4项胸肩随动及新增4项朝向参考回归均保留；全部795项单测、类型和lint通过。当前源码16组高低画质／基础照片角色／双手包表面检查与四组左右手持球包各5项真实照片WASD检查通过。最小净空约3.003毫米，仍接近原3毫米下限；这不代表所有体型或所有动作已获得额外裕量。

官方参考来自本机已核实来源的实际短片段，尤其腰腹双手持球与运球后收球。没有读取官方游戏资产或动捕，也不将短窗查看称为完整学习十部影片。运球回收侧向肘张、被动臂胸侧接触与出手／终结后肩肘恢复仍需继续精修。
