# 地形、湖面与入口收尾

本轮在 2026-10-16 已验收的湖岸成果上追加远近景衔接和真实场景倒影。保留既有浅水湖床、湿岸矿物色、细波远距衰减、真实地表三角面岸线和岸边植被，不覆盖原路线、骑行物理、音频及私人媒体。

近地表外侧 65–85 米逐渐接到共享远地表三角面；内侧道路及步行高度保持原样。两侧草地使用同一世界坐标颜色场，降低接缝处的色差。山体保留原 DEM 裁窗与对应航拍，纹理按屏幕像素足迹采样以抑制远景重复条纹。

湖面捕获实际场景中的山体和树木。中画质使用 512²、最多 4 Hz 的反射捕获，高画质为 768²、最多 6 Hz；低画质沿用天空反射。静止且减少动态时停止重复捕获，离开视锥、页面隐藏或资源尚在加载时跳过副通道。副通道保存并恢复渲染目标、视口、裁剪、XR 和阴影状态；共享天空与地表资源由原所有者管理。

入口调整石材和墙体的冷暖关系，保留深蓝门洞、开顶天空、暖侧光与玻璃光场；地面使用有限频率的柔化反射。入口天空和玻璃资源在 React 场景渲染前预载，消除冷启动进度通知导致的渲染警告。原玻璃几何、物理比例与受保护源码摘要保持。
