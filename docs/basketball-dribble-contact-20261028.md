# 运球掌面与落地衔接：2026-10-28

本轮修复主动运球手的接触位置、腕部回收和肩部参考系，以及急停起跳后的落地跳动。双手持球的肘部外张仍在后续精修范围，不能将本轮工程验收写成所有动作已自然或达到2K官方品质。

## 实现

- 掌心接触点与腕关节分开计算。原实现把腕骨放到掌心目标上，真实手部蒙皮在迎球时穿入球面约20–32毫米；现在按现有角色掌面的位置，从实际手掌旋转反推腕目标，再由实际腕骨回算掌心位置。
- 主动手的下压、屈腕、回收与迎球沿用同一运球相位；手腕继续服从原10rad/s旋转预算。肘部方向随真实肩线更新，避免下半身转向把手臂参考轴带偏；颈头补偿前倾，保持朝向场内。
- 起跳后逐渐退出脚部载荷动画的位移混合，避免着陆锚点更新时脚踝突然跳动。原53.9毫米/6.9毫秒的落地失败与修复回归均保留。
- 球的物理轨迹、碰撞、计分与全部既有验收门限保留。掌心位置现在来自真实骨架，新增检查独立核对标记是否靠近实际手部蒙皮。
