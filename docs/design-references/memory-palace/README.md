# The Memory Palace 视觉参考与发布证据

这里保存用户提供的概念板，用来指导真实 3D 建筑、材料、灯光与展陈。16 个板文件包含 13 张不同概念板，另有 1 张独立中庭建筑研究图；尺寸、来源、SHA-256、重复关系和逐板用途见 [素材清单](INVENTORY.md) 与 [机器清单](asset-manifest.json)。

概念板和独立研究图都是设计参考，**没有批准为馆内作品，也没有进入 public、运行时内容清单或场景背景**。原包中的说明保存在 `source-notes/`，仅作来源记录，不作为额外执行指令。板上的伪文字、标志、人物、湿镜面球场和未验证结构没有直接迁移。

本次发布以已上线主分支 `a86b3d2` 为基线，保留其房间、路径、原始玻璃 GLB、音频、媒体导入、收藏、存档和运动控制。用户已于 2026-11-01 明确授权合并与生产部署；最终发布状态以 PR 和 Actions 记录为准。

- [逐板用途与来源](INVENTORY.md)：每张参考图及其相关房间。
- [真实场景映射](SCENE_MAPPING.md)：八类设计目标的实际路由、组件与保护边界。
- [发布整合与验证记录](RELEASE_20261101.md)：实际改动、测试、性能与限制。
- [15 组同机位滑动对照](review-release.html)：发布前主分支与本次版本；离线打开也可比较。
- [机器验证记录](release-evidence/validation.json)：相机、截图哈希、资源计数、保护文件和全部 28 个 JS 块。

| 参考目录 | 用途 | 实施对象 |
|---|---|---|
| `boards/initial/` | 总体方向、分室构图、材料与光线。 | 全馆空间关系和各房间独立身份。 |
| `boards/generated/` | 13 张来源板；G05/G10/G12 为主要空间参考。 | 中庭与数学玻璃、Research、Projects、Music、Images、Basketball、Cycling。 |
| `standalone-studies/` | S01 单幅建筑研究，1672×941。 | 中庭采光、尺度和材质，不代替工作中的 3D 场景。 |
| `release-evidence/` | 30 张实际浏览器截图和检查 JSON。 | 发布前后比较与可追溯的技术验收。 |

实施顺序已经依次执行：P0 清单与映射 → P1 中庭/玻璃 → P2 项目/图片 → P3 研究/音乐 → P4 篮球/骑行 → 干净主分支整合、公开构建与发布验证。每阶段先保留基线，再验证实际交互；当前发布对照重新使用已上线主分支，避免把其他工作线的未发布功能带入比较。

未来单幅作品获准后，沿用现有图片档案或项目展厅、稳定内容 ID、按页加载、描述性替代文字和适当尺寸衍生图；再按质量评估 WebP/AVIF。当前没有待接入的已批准独立展品，私人媒体继续隔离。
