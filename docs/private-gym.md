# 私人健身房

从中庭左墙的「私人健身房」门、导览中的 `PRIVATE GYM`，或 `/private-gym/` 进入。初始视点对准训练区，返回门接回中庭并保留本次访问视角；刷新后的新访问使用默认入口。手机上的训练面板可展开、收起，留出人物画面。

## 训练模拟

七种动作全部提供：俯卧撑、徒手深蹲、平板支撑、哑铃弯举、哑铃肩推、卧推、负重深蹲。点击动作后开始；可暂停、重置，节奏在 0.5×–1.5× 之间调整。平板支撑显示模拟持续秒数，其余动作显示角色完整循环次数。动作切换包含站立与地面姿态过渡。遮挡、隐藏页面和离开房间会冻结或暂停训练。

动作使用独立克隆的角色骨骼、真实肢段长度和双手／双脚目标，不修改篮球、骑行动作时钟或公共模型缓存。器械跟随真实握点，负重深蹲的杠铃位于肩背。已有本机人物外观可继续用于训练角色。

## 我的照片与视频

点击「我的训练照片 / 视频」后从本机选择文件：

- 照片：JPG、PNG、WebP、AVIF，单张最多 30 MB、3200 万像素；照片墙显示最近八张。
- 视频：浏览器可播放的 MP4、WebM，单个最多 512 MB；选择一个视频到侧墙屏幕，再点击播放。默认静音，可开启声音。
- 原文件保存在当前浏览器、当前地址的独立 IndexedDB `memory-palace-private-gym` 中。缩略图与元数据单独保存；刷新保留记录，删除只清理选择的记录。
- 保存失败时可继续在本次会话使用，并明确提示刷新会丢失。不同浏览器或端口分别保存数据。

初始照片墙和视频屏保留真实空位。角色计数代表模拟过程，个人训练记录来自实际导入的文件。

导入检查包括 MIME、文件头、尺寸及解码。标题作为文本显示。媒体不进入公共馆藏清单，没有上传接口；离开时停止视频、清除视频源并释放自有 Blob URL 和纹理。

## 本地验收

`tests/fitness-motion.test.ts` 使用生产角色骨骼检查七种完整周期、49 种动作切换、暂停／变速时钟，以及肩背杠铃位置；真实腕足目标保持 3.5 厘米门限。`scripts/check-private-gym.mjs` 通过真实门、按钮和文件选择器检查七种动作、PNG／WebM 播放、刷新、精确删除、保存失败提示、手机布局和 URL 回收。测试图片与视频为专门生成的本机 QA 素材。

开发版证据：`qa-artifacts/private-gym/native-20261018-final/validation.json`，11 项流程通过、页面错误和上传请求均为零，运行前后源文件哈希一致。生产版 `qa-artifacts/private-gym/production-20261018/validation.json` 的 6 项真实流程通过，验证无开发调试入口、公共清单为空、导入播放、刷新删除、导览往返和手机展开／收起，错误与上传均为零。

本轮 67 个测试文件、657 项测试，以及 TypeScript、ESLint、公共生产构建均通过。原 5190 的集成检查与受保护文件校验另存于当前任务的交付记录。


## 2026-10-21 私人训练室材质与反射稳定性

保留七类训练、原模拟时钟、器械握点、通行范围与本机媒体流程。房间增加原创木地板和橡胶颜色／粗糙度／法线贴图（六张512×512自有纹理），训练区聚光阴影、窗格、木饰条与深绿档案墙。72根墙面饰条合并为一次实例绘制；新的哑铃橡胶端面与金属握杆区分反光。训练角色复用已有服装／皮肤／鞋面表面细节，继续保留原本机参考脸图，未创建或上传照片。

反复进出房间时发现旧中庭反射的实际GPU问题：每次新建Reflector的虚拟相机，Three会按该相机ID保留另一张玻璃透射渲染目标。修复前原项目与新副本均每轮增加一张纹理；保留了GL创建／删除与原生导览诊断。现在每个画布复用一个公共Reflector和虚拟相机，保留玻璃透射、反射预算与512／768分辨率，不读写引擎私有缓存。自有反射目标与几何保留为有界画布资源，在WebGL上下文丢失时释放。

新增4项所有权回归；全量75文件／698项、类型、lint及干净公共构建通过。重新执行的原生11项健身流程覆盖七类完整动作、媒体、刷新删除、保存失败、移动端和真实门往返，错误／上传／源码漂移为零。可见Edge同机前后短测均约60FPS，新版三样本59.8–60.2FPS，p95 16.8–16.9ms；视口及内部绘制均1920×1080，隐藏与失焦帧为零。三轮原生往返在预热后几何、纹理、程序数完全相等；中／高画质实际画面仍有玻璃透射与持续反射更新。此测量不能替代长时间温度测试。

证据在本机`qa-artifacts/night-20261020/gym-art-native-v2/`、`gym-art-performance-v2/`及`entry-mirror-native/`。最初资源增长失败的`gym-art-performance/`与`gym-texture-diagnostic/`保留。正式流程及原5190的最终接入结果另存本轮交付清单；篮球31个冻结运行时文件保持不变。
