# 私人健身房

从中庭左墙的「私人健身房」门、导览中的 `PRIVATE GYM`，或 `/private-gym/` 进入。初始视点对准训练区，返回门接回中庭并保留本次访问视角；刷新后的新访问使用默认入口。手机上的训练面板可展开、收起，留出人物画面。

## 训练模拟

七种动作全部提供：俯卧撑、徒手深蹲、平板支撑、哑铃弯举、哑铃肩推、卧推、负重深蹲。点击动作后开始；可暂停、重置，节奏在 0.5×–1.5× 之间调整。平板支撑显示模拟持续秒数，其余动作显示角色完整循环次数。动作切换包含站立与地面姿态过渡。遮挡、隐藏页面和离开房间会冻结或暂停训练。

动作使用独立克隆的角色骨骼、真实肢段长度和双手／双脚目标，不修改篮球、骑行动作时钟或公共模型缓存。器械跟随真实握点，负重深蹲的杠铃位于肩背。已有本机人物外观可继续用于训练角色。

## 我的照片与视频

点击「我的训练照片 / 视频」后从本机选择文件：

- 照片：JPG、PNG、WebP、AVIF，单张最多 30 MB、3200 万像素；照片墙显示最近八张。
- 视频：浏览器可播放的 MP4、WebM，单个最多 512 MB；选择一个视频到侧墙屏幕，再点击播放。默认静音，可开启声音。
- 原文件保存在当前浏览器、当前地址的独立 IndexedDB `memory-palace-private-gym` 中。缩略图与元数据单独保存；刷新保留记录，删除只清理选择的记录。
- 保存失败时可继续在本次会话使用，并明确提示刷新会丢失。不同浏览器或端口分别保存数据。

初始照片墙和视频屏保留真实空位。角色计数代表模拟过程，个人训练记录来自实际导入的文件。

导入检查包括 MIME、文件头、尺寸及解码。标题作为文本显示。媒体不进入公共馆藏清单，没有上传接口；离开时停止视频、清除视频源并释放自有 Blob URL 和纹理。
