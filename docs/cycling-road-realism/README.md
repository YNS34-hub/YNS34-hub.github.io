## 画面与证据方法

基线 `road-before` 是准确 `f9f0346`，最终画面使用 `fd3fd50`。相同存档距离、原第一人称相机、60° FOV、medium、DPR 1、同内容与光照；1920×1080 和 2560×1440 各检查森林入口、森林路面、高山山口、高山路面。新增路侧近景另作同位阶段比较。实际使用原步行 / 上车操作，只有摄影时的观看方向用于重现机位，没有向骑行物理注入速度或路线距离。

阶段 1 的首版 GLSL swizzle 错误、随后高山漆线缺失均被拒绝；分别修正后才保存。错误与失败图保留在本机 `qa-artifacts`，没有拿脚本退出成功代替查看画面。阶段截图在编码 / 生命周期优化后又复查近处静止构图。

公开证据均使用空私人清单、中性人物配置；WEBP 是原 PNG 的同尺寸压缩副本，A/B 联系图仅缩小 / 并排 / 加来源标签，未调色、生成或重画。报告保留当次真实 SHA、dirty、机位、显卡和帧间隔，不改写成最后文档提交。

[第二轮静止原始报告](evidence/performance-pre-cleanup.json) 在 `65fe184` 测量；之后 `fd3fd50` 只补实例缓冲的卸载清理，未改几何、材质、机位、光照。对照沿用第一轮 [原始采样](../cycling-environment/evidence/performance-after.json)，来源 `1ba7684`，之后第一轮只有加载准备和文档变动。最终移动采样另附实际 `fd3fd50` 报告。静止均值约保留第一轮的 95–100%，纹理数量相同；没有把不同时刻的小样本差异解释为确定因果。

最终 `fd3fd50` 的独立二十秒真实 W 踩踏为 **107.8 FPS 平均 / 14 ms P95 / 291.7 ms 最大帧间隔**，渲染帧 2158、重复 RAF 0、隐藏 / 无焦点 0；峰值 **121 calls / 2,101,215 triangles / 40 textures**。第一轮同方法为 109.3 FPS / 14 ms / 340.3 ms。额外构件仍保留主要性能余量，但分区停顿没有消除；不宣称全程最低 45 FPS，也不把两次短采样的最大值变化归因于缓冲修正。

计数来自 renderer.info 的主通道，不含阴影 / PMREM，纹理数量不是 VRAM。活动灯光仍为原太阳 / 半球灯。这不是全程最低 FPS、GPU timer 或长时间热稳态测试；明显分区停顿须单独保留，不能用高均值掩盖。

## 具体限制

环境整体仍有第一轮的简化：远林是树冠卡片，远山是低频地貌，部分原高山松散石块与粗地形之间仍有接触误差；本轮没有改这些构图 / 资产。湖面仍只有天空反射，没有山体、树木、自行车倒影。这里是 Three.js / WebGL 的道路细化结果，没有声称达到 UE5、Forza、Flight Simulator 或 AAA 引擎画质。

排水和砾石都是视觉构件，原可骑宽度 / 碰撞不变；没有天气、车辆或真实排水模拟。细节预设参考正常骑行观看距离，没有自由相机贴地显微材质模式。

未测：1440p FPS、DPR 2、长期热稳态、实体移动设备、本轮完整高山十公里原生行程；高山实际操作与独立存档另测短流。所有旧单测保留，但没有重新执行每条历史博物馆浏览器长旅程。
