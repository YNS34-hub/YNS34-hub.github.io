# Original spatial studies

These local assets were authored for The Memory Palace. They use no photographs, external music, sampled recordings or downloaded texture packs.

- **Threshold / Colonnade:** CPU ray-box intersection rendering with repeated architectural bays, directional shadows, atmospheric depth and restrained blue sky light.
- **Level Sets:** contours of a smooth nonlinear scalar field, illustrating a visual idea of level sets without claiming a mathematical theorem.
- **Blue Hour:** layered sinusoidal parametric horizons.
- **Nocturne:** original night-window geometry, distant silhouettes and water-like line reflections.
- **Palace Study — No. 01:** a 36-second stereo synthesized ambient composition, 22,050 Hz PCM WAV. Sine partials at 110, 164.8138, 220, 261.6256 and 329.6276 Hz, slowly changing envelopes and a short stereo offset; no audio samples.
- **og-palace.png:** original architectural study with local Nimbus Sans typography.

The source is `generate.py`. Regeneration is optional and is never needed to build or visit the site:

```bash
python -m pip install pillow numpy
python public/media/generated/generate.py
```

Project exhibition covers using these studies are explicitly described as gallery interpretations, rather than real screenshots of the associated projects. The ambient study is a site demonstration track, rather than a claim about the owner's favorite commercial music.
